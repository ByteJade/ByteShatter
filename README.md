# ByteShatter
(WIP) Linux userspace x64 -> ARM dynarec  
Goal: Make a simple and fast x64 dynamic recompiler  
### How to build
git clone https://github.com/ByteJade/ByteShatter  
cd ByteShatter && make  
### Use example
cd build  
./shatter ../tests/glxgears
